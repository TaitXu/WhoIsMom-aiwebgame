# Who is Mom

《Who is Mom》是一款以《小蝌蚪找妈妈》为原型的 AI 原生小队管理与轻推理网页游戏。玩家带领三只性格不同的蝌蚪探索一张由九个全屏区域连成的 3D 水乡，通过隐藏调查、有限记忆、同伴对证、环境协作和跳跃学习，判断三只候选青蛙中谁才是妈妈。

当前仓库包含一个可完整通关的 Three.js Demo，重点验证“管理 Agent 的认知上下文”是否能成为实际玩法，而不是只把 AI 用作对白生成器。游戏需要连接兼容 OpenAI `chat/completions` 的大模型；模型不可用时不会伪造本地记忆，而是阻止开局或暂停当前游戏。

## 当前玩法

- 在 `3×3` 连续地图中上下左右自由移动，探索 NPC、障碍、通道和候选妈妈；
- 墨点、小浪、泡泡的名字固定，但每局会重新分配性格，并由 AI 生成玩家不可见的心理档案与说话规则；
- 每次重新开始都会重新生成妈妈身份、外观特征、干扰项和与之匹配的文字证据；
- 一次派出 `1-3` 只蝌蚪调查 NPC，玩家看不到原始对话，只能读取它们带回的性格化记忆；
- 对话会携带该 NPC 的历史交谈和已见事实，同一动物面对不同蝌蚪、不同轮次会保持性格差异和前后关系；
- 屏幕内 NPC 无需玩家靠近即可悬浮、点击和派遣，蝌蚪仍会实际游到目标处再开始交谈；
- 每只蝌蚪初始拥有 3 个记忆槽，新信息可能覆盖旧认知；
- 两只蝌蚪只有在拥有共同议题时才能对证，结果会确认、质疑或修正记忆；
- 记忆槽按状态区分底色：清晰、正在流失和已模糊使用不同视觉反馈；
- 线索本只收录已对证且仍然清晰的证据，不收录跳跃技能或对证过程中的提示文字；
- 分配 `1-2` 只蝌蚪清理六种环境障碍，获得灵感并把记忆容量扩充到 4 或 5 格；
- 跳跃是独立技能，不占用记忆槽；蝌蚪可从不同 NPC 的相关对话或同伴教学中学会，掌握时会明确提示；
- 一只会跳跃的蝌蚪可独自越过蜻蜓叶隙侦察，三只都学会后才能通过莲叶长桥；
- 蝌蚪会积累疲劳，回到孵化静池可以让全队休息；
- 证据不完整时仍可和候选妈妈交谈，但至少确认两个独立 NPC 来源后才能作出最终选择；
- 正确和错误选择都会进入结算，并展示本局证据链；
- 场景包含缓慢摆动的树冠投影，按钮、水花、口哨、线索和结算均有轻量音效。

## 操作

- `WASD` / 方向键：移动领路小鱼；
- 点击或轻触水面：移动到目标位置；
- `1-3`：选择蝌蚪；
- `R`：召回当前选择的蝌蚪；
- `空格`：吹口哨，在涟漪范围内召回蝌蚪；
- `M` / `Tab`：打开或关闭线索本，右上角“线索”按钮也可打开；
- 悬浮或点击屏幕内 NPC：远程派遣所选蝌蚪前往聊天；
- 点击障碍、荷叶门或青蛙：靠近后执行上下文操作；
- 移动端使用屏幕方向键和同一套大色块操作面板；
- 设置面板：切换默认/自定义模型，开启或关闭游戏音效。

## 本地运行

> 这是 Vite 项目，不能直接双击 `index.html` 完整运行。请使用开发服务器启动。

```bash
npm install
npm run dev
```

Vite 会输出本地访问地址，默认通常为 `http://127.0.0.1:5173/`。开发服务器会在 Node 侧挂载 `/api/agent`。

### 大模型连接要求

游戏开始时会直接请求本局角色。只有真实模型返回通过约束验证的角色后才会进入游戏；没有配置 API、网络失败或模型不可用时，游戏会留在标题页。运行中连接中断则暂停当前 AI 行为，不会使用本地结果生成替代记忆。

### 配置默认模型

仓库不包含作者的 API Key。克隆项目的使用者需要配置自己的模型服务：

```bash
cp .env.example .env.local
```

编辑 `.env.local`：

```dotenv
MODEL_BASE_URL=https://api.siliconflow.cn/v1
MODEL_API_KEY=your-api-key
MODEL_NAME=zai-org/GLM-5.2
MODEL_TIMEOUT_MS=90000
```

重启 `npm run dev` 后，设置面板的“默认模型”会使用这些服务端环境变量。`.env.local` 已被 Git 忽略，不会上传到仓库；不要把 Key 写入前端源码或任何 `VITE_*` 变量。

另一种方式是在游戏设置中选择“自定义模型”，填入兼容 OpenAI `/chat/completions` 的 HTTPS Base URL（或完整的 `/chat/completions` 地址）、模型名和 Key。这些信息仅保存在当前浏览器的本地存储中，并由同源 `/api/agent` 代理请求。

在 URL 后添加 `?debug=1` 可显示区域跳转面板：

```text
http://127.0.0.1:5173/?debug=1
```

## AI 接入

浏览器只调用同源 `/api/agent`，不直接内置任何默认 Key。设置面板提供“默认模型 / 自定义模型”：

- **默认模型**：使用服务端配置的 `MODEL_*` 环境变量；未配置或连接失败时不允许开始游戏。
- **自定义模型**：使用玩家保存在当前浏览器中的 Base URL、模型名和 Key，再由 `/api/agent` 转发。

### 部署给其他人

部署到 Vercel 时，在项目的 Environment Variables 中配置同样的 `MODEL_*` 变量。这样用户访问你部署的网站时可以使用服务端默认模型，但克隆 GitHub 仓库到自己电脑的人仍不会获得你的 Key。

如果要开放一个共享的默认模型后端，应额外增加身份验证、请求限流、用量配额和成本监控，不要将 Key 写入 GitHub 或浏览器代码。

代理支持五类受约束任务：

- `encode_memory`：把允许的事实压缩为带性格偏差的记忆；
- `reconcile_memories`：对当前议题的两组记忆进行确认、质疑或修正；
- `judge_jump_learning`：根据训练内容、性格和隐藏档案判断掌握程度；
- `generate_cast`：为固定名字的蝌蚪生成本局性格档案和对话风格，并为候选青蛙生成中性名字；
- `decide_movement_intent`：低频选择白名单行为意图，本地系统仍负责连续轨迹、碰撞和召回。

模型只能引用请求中提供的 Fact ID 或 Memory ID。网络、超时、格式或越权结果失败时会暂停模型相关流程，不会生成本地替代记忆。

移动系统使用“地形硬碰撞 + 角色软分离”。玩家不会被蝌蚪围住，岸线碰撞会尝试多角度局部滑行，点击到不可走区域时会搜索邻近落点；持续无进展会取消自动导航或召回任务中的蝌蚪。固定地图因此不需要引入 NavMesh 或 A*。
