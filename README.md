# Who is Mom

《Who is Mom》是一款以《小蝌蚪找妈妈》为原型的 AI 原生小队管理与轻推理网页游戏。玩家带领三只性格不同的蝌蚪探索一张由九个全屏区域连成的 3D 水乡，通过隐藏调查、有限记忆、同伴对证、环境协作和跳跃学习，判断三只候选青蛙中谁才是妈妈。

当前仓库包含一个可完整通关的 Three.js Demo，重点验证“管理 Agent 的认知上下文”是否能成为实际玩法，而不是只把 AI 用作对白生成器。

## 当前玩法

- 在 `3×3` 连续地图中上下左右自由移动，探索 NPC、障碍、通道和候选妈妈；
- 一次派出 `1-3` 只蝌蚪调查 NPC，玩家看不到原始对话，只能读取它们带回的性格化记忆；
- 每只蝌蚪初始拥有 3 个记忆槽，新信息可能覆盖旧认知；
- 两只蝌蚪只有在拥有共同议题时才能对证，结果会确认、质疑或修正记忆；
- 分配 `1-2` 只蝌蚪清理六种环境障碍，获得灵感并把记忆容量扩充到 4 或 5 格；
- 小浪会自主接近弹簧蚱蜢。跳跃是否真正学会由受约束 AI 判断，也可以通过同伴教学传播；
- 一只会跳跃的蝌蚪可独自越过蜻蜓叶隙侦察，三只都学会后才能通过莲叶长桥；
- 蝌蚪会积累疲劳，回到孵化静池可以让全队休息；
- 证据不完整时仍可和候选妈妈交谈，但至少确认两个独立 NPC 来源后才能作出最终选择；
- 正确和错误选择都会进入结算，并展示本局证据链。

## 操作

- `WASD` / 方向键：移动领路小鱼；
- 点击或轻触水面：移动到目标位置；
- `1-3`：选择蝌蚪；
- `R`：召回当前选择的蝌蚪；
- `M` / `Tab`：打开或关闭记忆面板；
- 点击 NPC、障碍、荷叶门或青蛙：在距离允许时执行上下文操作；
- 移动端使用屏幕方向键和同一套大色块操作面板。

## 本地运行

```bash
npm install
npm run dev
```

Vite 会输出本地地址。只运行 Vite 时 `/api/agent` 不存在，客户端会自动使用确定性的本地 Agent 回退，因此无需配置模型也能完整通关。

在 URL 后添加 `?debug=1` 可显示区域跳转面板：

```text
http://127.0.0.1:5173/?debug=1
```

## AI 接入

浏览器只调用 `/api/agent`，模型密钥保存在服务端环境变量。代理支持三类受约束任务：

- `encode_memory`：把允许的事实压缩为带性格偏差的记忆；
- `reconcile_memories`：对当前议题的两组记忆进行确认、质疑或修正；
- `judge_jump_learning`：根据性格和跳跃记忆判断掌握程度。

模型只能引用请求中提供的 Fact ID 或 Memory ID。网络、超时、格式或越权结果失败时会自动使用本地规则，不影响流程。
